#### 小根堆/大根堆

不需要自己手写，C++ 已经提供了对应的数据结构

每次 pop / top（弹出、访问根节点），小根堆都是最小，大根堆都是最大

```c++
#include <queue>
// 小根堆
priority_queue<int, vector<int>, greater<int>>
// 大根堆
priority_queue<int, vector<int>, less<int>>
```
