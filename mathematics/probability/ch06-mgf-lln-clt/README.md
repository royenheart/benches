# ch06 · 矩母函数、大数律、中心极限定理

> 给出"为什么均值是几的稳定估计""为什么样本多就能换成正态"两条铁律, 让你能在 ML 工程中判断极限分布与估计误差量级。

## 学习目标

- 推矩母函数 (MGF) 与特征函数 (CHF) 的差别
- 写出 Khinchine 弱大数律 (WLLN) 与 Kolmogorov 强大数律 (SLLN) 的区别
- 论证 CLT 的表达式与 $\\sqrt n$ 量级
- 写一段标准化指数 (-1) 样本均值随 n 的收敛分配 - 验证 CLT
- 给出 Berry-Esseen 界限的工程直觉

## 场景

1. **Sample size 决断**: Hoeffding 不等式告诉你需要 N 多大
2. **误差棒**: 量级 $1/\\sqrt n$ vs $1/n$
3. **梯度噪声分析**: SGD 下梯度分布由 CLT 给出
