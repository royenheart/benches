# ch01 · 样本空间、事件、概率公理 + 排列组合

> 把 ch00 的概率直觉正式化为可加公理体系；专门讨论"排列组合何时该用、何时是被坑"。
> 学完你能写出套事件空间示意图；理解可加性如何成为后续所有概率建模的地基；并能避免用排列组合把简单问题算成天文数字。

## 学习目标

- 用 3 条公理独立验证"生日悖论"概率，不靠死记公式
- 区分 **排列**（sequence, order matters）vs **组合**（subset, order irrelevant），何时各自用上
- 处理有放回/无放回、可区分/不可区分组合导致的 4 种计数情形
- 写一段蒙特卡洛验证组合数 $\\binom{n}{k}$ 的精确公式
- 看到 "去抽 N 个里抽 k 个" 类问题时立刻选对计数策略

## 三个能立刻解决的场景

1. **生日悖论**：23 人房间同生日概率 ≈ 50% 这条直觉反例，亲手用公理 + 计数算出来
2. **抽奖数学**：彩票中头奖概率的正确算路径，得出到底该用 $\\binom{n}{k}$ 而不是 $A_n^k$
3. **抽样调查**：有放回/无放回两种抽样下"恰好 k 个不同"的概率公式不同
