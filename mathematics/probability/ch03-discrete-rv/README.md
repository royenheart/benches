# ch03 · 离散型随机变量

> 引入"在数值上做概率"的随机变量概念，把事件空间映射到数值；专门给工程常用离散分布做出"分布选择决策树"。

## 学习目标

- 区分 PMF vs CDF vs PDF 并熟练互换
- 写出伯努利 / 二项 / 几何 / 泊松 / 负二项的 PMF、均值、方差、典型场景
- 用泊松近似二项的严格条件（$n\\to\\infty, p\\to 0, np\\to\\lambda$）
- 写一段优先适用分布决策树，看任务能立刻选对
- 用蒙特卡洛验证泊松近似二项在不同 (n, p) 下的吻合度

## 三个能立刻解决的场景

1. **超卖合理库存**：n 张票订 n+5 张超额销售 → 实际到场的客数 ~ Bin(n+5, 0.95)；报可接受 risk
2. **A/B 测试**：CTR 的伯努利模型 → beta-binomial 共轭（接 ch02）
3. **API 限流**：单位时间请求数 ~ Pois(λ)，用 λ 推算 P95 延迟
