# Environment Notes

## Required for the Base Repository

- Git with Git LFS.
- A C/C++ compiler with C++17 support.
- xmake for project builds and test execution.

## Optional Accelerator and Parallel Dependencies

- OpenMP runtime and compiler flags.
- MPI implementation and `mpirun`.
- CUDA toolkit for CUDA labs.
- OpenCV for CUDA image and simulation examples.
- OpenBLAS, MKL, or KML for BLAS-backed experiments.
